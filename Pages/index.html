Abstract

This paper investigates the effectiveness of Retrieval Augmented Generation (RAG) in enhancing program code generation capabilities of Large Language Models (LLMs). We conduct a systematic analysis using Qwen2.5-Coder, a stateof- the-art code generation model, across multiple experimental scenarios with varying degrees of retrieval augmentation and selfevaluation techniques. Our experiments on the MBPP+ benchmark reveal that RAG significantly improves code generation performance by up to 10.11% in pass@1 metrics compared to baseline approaches, with self-evaluation mechanisms further enhancing results by addressing edge cases and logical errors. We also demonstrate that optimal RAG implementation requires careful consideration of retrieval scope and relevance scoring. This work provides empirical evidence for the practical impact of RAG in code generation applications and offers insights into effective implementation strategies.

Method

Retrieval Augmented Generation

Our RAG implementation integrates external code repositories to provide contextual examples during generation. The system retrieves relevant code snippets based on semantic similarity, which are then used to augment the model's context window.

Architecture of the Retrieval Augmented Generation system.

Self-Evaluation Framework

The self-evaluation mechanism employs iterative refinement where the model critiques its own outputs and generates improved versions. This process continues until quality thresholds are met or maximum iterations are reached.
